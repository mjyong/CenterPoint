# 我们在 Nav_D20 上的改动

`Nav_D20/` 是机器人团队的代码（定位 lightning、感知、规划），我们在上面改了几处。**下次从机器人团队同步代码时，先看这一页**：

- 2026-11-12 那次同步（04d3a34）把下面大部分改动冲掉了，T47 复核时又重新打上；回放超时那一条当时没记在这里，漏了，到 T48 才发现（回放进 standstill 再也不恢复）；
- 同步以后对一遍这张表：每条的"怎么验"里有能直接 grep 的符号（`TimeoutReference`、`ins_yaw_offset`、`allow_collision_start`……）；
- 能并进机器人团队那边最好，就不用每次重打。

每条写了改在哪、为什么、怎么验。重打时用 git 的三方合并：`git diff <改动提交>^ <改动提交> -- <文件> | git apply --3way`。冲突要手动看：
- 机器人团队把那段代码删了或注释了，就不用再改；
- 否则按"为什么"那一栏重新改。
